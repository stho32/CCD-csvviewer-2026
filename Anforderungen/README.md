# Anforderungen

Anforderungs-Dokumente fuer CsvViewer.

## Konvention

- **Dateiname**: `RNNNNN-kebab-case-zusammenfassung.md` (5-stellig, fuehrende Nullen) — z.B. `R00001-csv-datei-anzeigen.md`
- **Status-Werte**: `Neu`, `In Arbeit`, `Erledigt`
- Anforderungsdateien sind feste Vorgaben — nach Erstellung nicht mehr verändern (außer via `/aktualisiere-anforderung`)

## Neue Anforderung

`/erstelle-anforderung` — vergibt automatisch die nächste freie R-Nummer.
