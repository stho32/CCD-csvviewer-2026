# User Stories — R00003: Interaktiver Viewer

## Mehrwert

Als Nutzer kann ich eine CSV-Datei direkt im Terminal öffnen und ohne zusätzliche
Werkzeuge seitenweise lesen. Die Ein-Tasten-Navigation hält den Bedienfluss kurz,
während klare Fehlermeldungen verhindern, dass ungültige Aufrufe oder Dateien zu
unkontrollierten Programmabbrüchen führen.

## US1 — Viewer starten und erste Seite sehen

> Als Nutzer will ich eine CSV-Datei per `csvviewer datei.csv` öffnen, damit ich sofort die erste Seite als Tabelle sehe.

### Szenario 1.1 — Standard-Seitengröße

- **Given** eine gültige CSV-Datei mit elf Datenzeilen
- **When** ich `csvviewer datei.csv` aufrufe
- **Then** wird vor der Ausgabe die Konsole geleert
- **And** die erste Seite enthält genau die ersten zehn Datenzeilen
- **And** unter der Tabelle steht das Navigationsmenü

### Szenario 1.2 — Datei nur mit Kopfzeile

- **Given** eine gültige CSV-Datei, die nur eine Kopfzeile enthält
- **When** ich den Viewer starte
- **Then** wird genau eine Seite mit Kopfzeile, Trennlinie und Menü angezeigt

## US2 — Durch Seiten navigieren

> Als Nutzer will ich per Tastendruck zwischen Seiten wechseln, damit ich alle Datensätze durchsehen kann.

### Szenario 2.1 — Vorwärts und rückwärts navigieren

- **Given** ein Dokument mit drei Seiten und angezeigter erster Seite
- **When** ich `N`, `N` und danach `P` drücke
- **Then** werden nacheinander die zweite, dritte und wieder die zweite Seite angezeigt
- **And** vor jeder Darstellung wird die Konsole erneut geleert

### Szenario 2.2 — Erste und letzte Seite direkt wählen

- **Given** ein Dokument mit drei Seiten und angezeigter zweiter Seite
- **When** ich `L` und danach `F` drücke
- **Then** werden nacheinander die letzte und die erste Seite angezeigt

### Szenario 2.3 — Navigation klemmt an den Rändern

- **Given** die erste Seite ist ausgewählt
- **When** ich `P` drücke
- **Then** bleibt der Seitenindex unverändert
- **Given** anschließend die letzte Seite ist ausgewählt
- **When** ich `N` drücke
- **Then** bleibt der Seitenindex erneut unverändert

### Szenario 2.4 — Ungültige Taste ignorieren

- **Given** die zweite Seite ist ausgewählt
- **When** ich eine unbekannte Taste drücke
- **Then** bleibt der Seitenindex unverändert
- **And** dieselbe Seite wird ohne zusätzliche Fehlermeldung neu gezeichnet

### Szenario 2.5 — Groß-/Kleinschreibung und Beenden

- **Given** der interaktive Viewer läuft
- **When** ich Navigationsbuchstaben in Groß- oder Kleinschreibung drücke
- **Then** wird jeweils dieselbe Navigationsaktion ausgeführt
- **When** ich `E` oder `e` drücke
- **Then** endet der Viewer erfolgreich mit Exit-Code 0

## US3 — Seitengröße vorgeben

> Als Nutzer will ich die Datensätze-pro-Seite optional als zweites Argument setzen, damit ich die Ansicht an mein Terminal anpassen kann.

### Szenario 3.1 — Benutzerdefinierte Seitengröße

- **Given** eine gültige CSV-Datei mit 41 Datenzeilen
- **When** ich `csvviewer datei.csv 40` aufrufe
- **Then** enthält die erste Seite 40 Datenzeilen
- **And** die zweite Seite enthält die verbleibende Datenzeile

## US4 — Klare Rückmeldung bei Fehlbedienung

> Als Nutzer will ich bei falschem Aufruf oder fehlerhafter Datei eine verständliche Meldung statt eines Absturzes.

### Szenario 4.1 — Ungültige Argumentanzahl

- **Given** kein Dateipfad oder mehr als zwei Argumente wurden angegeben
- **When** der Viewer startet
- **Then** wird keine Datei gelesen und kein Viewer angezeigt
- **And** eine knappe Usage-Meldung erscheint
- **And** das Programm endet mit einem Exit-Code ungleich 0

### Szenario 4.2 — Ungültige Seitengröße

- **Given** die Seitengröße ist nicht numerisch, null oder negativ
- **When** der Viewer startet
- **Then** wird keine Datei gelesen und kein Viewer angezeigt
- **And** eine verständliche Fehlermeldung erscheint
- **And** das Programm endet mit einem Exit-Code ungleich 0

### Szenario 4.3 — Datei- oder CSV-Fehler

- **Given** die Datei fehlt, ist leer oder enthält eine Zeile mit falscher Feldzahl
- **When** der Viewer startet
- **Then** wird kein Navigations-Loop begonnen
- **And** eine ursachenspezifische Fehlermeldung erscheint
- **And** das Programm endet mit einem Exit-Code ungleich 0
