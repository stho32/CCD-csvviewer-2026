# User Stories — R00002: Seite als Tabelle rendern

## US1 — Lesbare Tabellenansicht

> Als Nutzer will ich eine Seite als ausgerichtete Tabelle mit Kopfzeile und Zellrändern sehen, damit ich die Datensätze schnell erfassen kann.

- **Given** eine Kopfzeile und eine Menge von Datensätzen
- **When** die Seite gerendert wird
- **Then** erhalte ich Kopfzeile, Trennlinie und Datenzeilen im Kursformat (`|` als Spaltentrenner, `-`/`+` als Trennlinie)

## US2 — Spaltenbreite passt sich der Seite an

> Als Nutzer will ich, dass jede Spalte genau so breit ist wie ihr längster Wert auf der aktuellen Seite (inkl. Spaltenname), damit die Ausgabe kompakt und bündig ist.

- **Given** eine Seite mit unterschiedlich langen Werten je Spalte
- **When** die Seite gerendert wird
- **Then** entspricht jede Spaltenbreite dem längsten Wert dieser Spalte inklusive Kopfzeile, und alle `|` stehen bündig untereinander

## US3 — Generisch für beliebige Spalten

> Als Entwickler will ich beliebige CSV-Strukturen rendern können, ohne den Renderer an ein Fachmodell zu binden.

- **Given** Seiten mit verschiedener Spaltenzahl und -benennung
- **When** ich sie nacheinander rendere
- **Then** funktioniert das Rendering rein positionsbasiert über Header und Feldwerte, ohne typgebundene Klasse
